For these **four Finance areas**, I would design them as one connected financial system rather than four independent pages.

The structure should be:

```text id="j9m8af"
Finance
├── Overview
├── Transactions
├── Subscriptions
└── Invoices & Receipts
```

The **Finance Agent** gets data primarily from your Inbox/email/document pipeline, but Finance itself becomes the structured source of truth for financial records.

---

# 1. Finance Overview

The Overview is not where you manually enter information. It is an **intelligence dashboard generated from the financial data**.

It should answer:

> How much money came in, how much went out, what is coming up, what looks unusual, and what needs attention?

## Core information

```text id="j7w8x2"
Total Balance
Available Balance
Income
Expenses
Net Cash Flow
Pending
Upcoming Payments

```

For multiple accounts:

```text id="5fq3qk"
Accounts
├── SBI
├── Jio Finance
├── Credit Card
└── Other
```

Don't manually aggregate balances. The system should calculate them from account/statement data where possible.

# 50. Final Finance architecture

```text id="5n8q2w"
                         FINANCE
                            │
          ┌─────────────────┼──────────────────┐
          │                 │                  │
      OVERVIEW         TRANSACTIONS       SUBSCRIPTIONS
          │                 │                  │
          │                 │                  │
          └─────────────────┼──────────────────┘
                            │
                    INVOICES / RECEIPTS
                            │
                            ▼
                     FINANCIAL RECORDS
                            │
       ┌────────────────────┼────────────────────┐
       ▼                    ▼                    ▼
    BANKING             INVESTMENTS          LIABILITIES
       │                    │                    │
       └────────────────────┼────────────────────┘
                            │
                       SOURCE DOCUMENTS
                            │
                         INBOX
                            │
                          EMAIL
```

The most important principle for your Finance module is:

**Inbox discovers financial information → Documents preserve the source → Finance Agent extracts and validates → Finance stores structured records → Finance Overview calculates the current picture → Reminder/Notification systems handle future obligations.**

That keeps your financial system auditable and prevents the same payment, receipt, statement, or invoice from becoming four separate pieces of conflicting data.
