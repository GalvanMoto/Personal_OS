# 1. Add "Client Account / Brand" hierarchy

Your current Client model should support:

```text
Client
└── Accounts / Brands
```

For you:

```text
Client
Karna Kreative

    ↓

Accounts / Brands
├── WOW Indian
├── Restaurant A
├── Restaurant B
└── Restaurant C
```

This distinction is important.

### Client

The entity that pays/hires you.

### Brand / Account

The business or brand under that client that you perform work for.

### Project

A larger campaign/workstream.

### Recurring Commitment

What you are expected to deliver repeatedly.

### Task

One actual execution instance.

# 4. A commitment is not a task

This distinction is critical.

### Commitment

> 3 reels every week.

### Task

> WOW Indian — Reel #1 — Week of Aug 31.

The commitment stays forever.

Tasks are generated from it.
